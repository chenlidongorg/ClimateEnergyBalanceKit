# Climate energy-balance review — 2026-10-04

The model represents a global-mean **temperature anomaly** relative to a balanced reference. It does not predict absolute temperature, regional climate, a calendar year or measured climate sensitivity. All four existing preset identities, defaults, parameter ranges, controller aliases, public Home arguments, lifecycle/interaction events and iOS 15 minimum are retained.

The convention is `S̄=340 W/m²`, `a₀=0.30`, `ASR₀=OLR₀=238 W/m²`. Global averaging and the approximate reflected fraction follow [NASA's energy-budget explanation](https://science.nasa.gov/earth/earth-observatory/climate-and-earths-energy-budget/). Values are explicit teaching constants, not a current satellite-data retrieval.

The linear equation is `C dΔT/dt_year = F − λΔT`, where `F=340 m(1−a)−238+3.7 log₂(CO₂/C₀)` and positive `λ` is **restoring damping**. This is the negative of IPCC's signed feedback coefficient in `ΔN=ΔF+αΔT`; the source equation and scope are described in [IPCC AR6 WGI chapter 7](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-7/). Existing restoring modes 0.85/1.10/1.35 W/(m² K) are illustrative; they are not posterior uncertainty estimates. The old ambiguous feedback-strength label is replaced in the active UI by a new explicit label, while existing translations remain preserved.

The original coefficient **3.7 W/m² per doubling** is deliberately retained as the rounded older logarithmic approximation `5.35 ln2≈3.71`, referenced in [IPCC TAR table 6.2](https://archive.ipcc.ch/ipccreports/tar/wg1/222.htm). The UI and export distinguish it from AR6's CO₂-doubling effective forcing estimate **3.93±0.47 W/m²**. They never label this simplified calculation an AR6 forecast. No clouds, changing forcing, spatial transport or layered ocean are solved.

For constant parameters the response is evaluated without Euler accumulation error: `ΔT(t)=(F/λ)(1−exp(−λt/C))`, using `expm1` near zero. The preset capacities 6/10/18 have units **W year/(m² K)**. A model year is exactly 365 days or 31,536,000 seconds; thus `C_SI=C×31,536,000 J/(m² K)`. `ΔQ=C_SI ΔT` and `dΔQ/dt_seconds=N` provide the SI heat budget. The absolute-anomaly reference `ΔT=0` does **not** mean an Earth temperature of 0°C.

Current output is evaluated at the actually revealed or inspected day: `ASR=340m(1−a)`, `OLR=238−F_CO₂+λΔT`, `N=ASR−OLR=F−λΔT`. This fixes the original error where the final eight-year OLR was shown as the day-zero live output. Total forcing `F` and instantaneous imbalance `N` remain separate. Increasing capacity changes the transient and time constant, not equilibrium. The larger-capacity preset retains CO₂ doubling; its active description compares with that preset rather than claiming a capacity-only change from baseline.

One chart uses a shared ΔT axis and a fixed 0–8-year domain for both curves; its bounds include the full forecast and remain unchanged during reveal. This fixes the old export's independent per-curve normalization. Orange/gray distinguish scenario/reference. SW orange and LW purple energy arrows are schematic, flux-proportional representations: thermal infrared is invisible, and the purple arrow is not a physical visible color. Native and PNG backgrounds/text resolve actual light/dark traits.

The 2,920-day animation is a finite teaching **observation window**, not a natural physical endpoint. It completes once, never loops or silently restarts. Pause/resume preserves fractional presentation phase, elapsed active time controls pacing, long suspension catch-up is capped, backgrounding pauses and returning requires an explicit resume. Parameter changes intentionally start a new zero-anomaly scenario, as before. A pause no longer emits a false completion event. Weak task ownership allows the view/model to be released.

Two-finger observation uses the common bounded 1–3× stage. The only single-finger interaction is an observational time probe on already revealed chart points; it changes no climate parameter, clock or history. Interrupted, resized or removed gestures roll back incomplete probe transactions; stale cancellation cannot overwrite a newer transaction. There is no physical draggable apparatus in a zero-dimensional reservoir.

The full PNG keeps the actual native viewport at its pixel dimensions, then appends all physical parameters, scope, current/revealed/probe state, fluxes, SI heat, pacing and **all 2,921 computed daily points** without downsampling. Future points beyond visibleDay are explicitly predictions, not observations. Rows use measured ≥14-point text; the caller's QR has an independent white quiet-zone footer. Initial, collapsed-title, focused and minimized-readout states do not omit the scientific record.
